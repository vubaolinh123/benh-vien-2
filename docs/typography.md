# Phông chữ Đại An

Theo ảnh nhận diện khách hàng cung cấp: Exo (font logo), SVN-Gilroy (font văn bản).
Website giữ nguyên logo ảnh; áp dụng Exo cho tiêu đề và SVN-Gilroy cho nội dung / điều khiển.

Font nhúng tại chỗ, không phụ thuộc Google Fonts hoặc CDN khi chạy.
- Exo variable 100–900: https://github.com/google/fonts/tree/main/ofl/exo (OFL đi kèm).
- SVN-Gilroy Light 300 / Bold 700: https://fonts.cdnfonts.com/css/svn-gilroy.

Bản webfont SVN-Gilroy hiện có hai độ đậm Light/Bold. Nội dung dùng Light, nhấn mạnh dùng Bold; chưa có file Regular/Medium riêng từ bộ nhận diện. CSS không đổi tên font khác thành SVN-Gilroy. Cần đối chiếu quyền nhúng web của bộ font thương hiệu trước khi vận hành thương mại chính thức.
